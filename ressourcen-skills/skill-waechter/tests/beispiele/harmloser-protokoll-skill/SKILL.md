# Protokoll

1. Stichpunkte lesen.
2. Gliederung: Teilnehmende, Themen, Entscheidungen, Aufgaben (wer, was, bis wann).
3. Offene Fragen am Ende sammeln.
4. Keine Inhalte erfinden; fehlt etwas, als Frage markieren.
